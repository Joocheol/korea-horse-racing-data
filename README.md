## 현재 범위

**파일럿: 2020·2021년.** 기존 아카이브에 통째로 빠져 있는 두 해를 API로 복구합니다.

- 공공데이터포털 KRA OpenAPI 우선 수집
- API에 없는 필수 자료만 KRA 공식 사이트에서 보완
- 경주 시행, 국내 발매, 배당시장 형성을 구분
- raw·staged·curated 계층과 체크섬·수집 이력을 보존
- push와 장시간 수집을 분리하고 수동 승인·preflight 후 실행
- `totalCount`뿐 아니라 기본키·페이지 경계·고유 행 수를 독립 검산

## 조사로 확인된 핵심 사실

- 7승식 **전체 배당 격자**를 공개 API로 받을 수 있다. HTML 스크레이핑이 필요 없다.
- API 값과 KRA 배당판 HTML 값은 셀 단위로 **100% 일치**한다(표본 804셀).
- `numOfRows` 실제 상한은 100,000이다(문서의 3,000이 아님). 경마장 × 월 단위
  수집이 가능하고, 전 역사가 약 3,700회 호출이면 끝난다.
- 표시상한 `9999.9`는 API에도 그대로 있다. 검열 문제를 API로 우회할 수 없다.
- **API에 시험 기록이 섞여 있다.** 요일로 걸러서는 안 되고, 매출액·착순
  존재 여부로 판별한다.
- 기존 아카이브에 **약 390경주(2%)가 누락**되어 있다. API를 상시 대조
  기준선으로 두어야 한다.

자세한 내용과 근거 수치는 [docs/API_FINDINGS.md](docs/API_FINDINGS.md)에 있습니다.

## 공개 원칙

코드, API 기반 정규화 데이터, 매니페스트와 품질보고서는 공개합니다. API 인증키,
GitHub Actions Secret, 개인 저장경로, 이용조건이 별도로 확인되지 않은 KRA 웹
원문은 공개하지 않습니다.
