# Korea Horse Racing Data

한국 경마 공개데이터를 재현 가능하게 수집·검증·배포하기 위한 비공식 연구 프로젝트입니다.

## 현재 범위

- 2020·2021년 누락 구간 복구
- 공공데이터포털 KRA OpenAPI 우선 수집
- API에 없는 필수 자료만 KRA 공식 사이트에서 보완
- 경주 시행, 국내 발매, 배당시장 형성을 구분
- 원응답·정규화 자료·체크섬·수집 이력을 보존

## 공개 원칙

코드, API 기반 정규화 데이터, 매니페스트와 품질보고서는 공개합니다. API 인증키,
GitHub Actions Secret, 개인 저장경로, 이용조건이 별도로 확인되지 않은 KRA 웹
원문은 공개하지 않습니다.

## 비공식 프로젝트

이 저장소는 한국마사회가 운영하거나 보증하는 공식 저장소가 아닙니다.
원자료 출처는 한국마사회와 공공데이터포털입니다.
