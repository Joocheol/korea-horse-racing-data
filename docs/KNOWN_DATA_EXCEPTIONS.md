# KRA 데이터의 확인된 예외와 판정 규칙

*최종 정리: 2026-08-23*

이 문서는 2016–2025 KRA API 정본과 기존 HTML 배당판을 대조하면서 이미 원인을
확인한 사례를 보존한다. 목적은 같은 경주를 반복해서 이상 사례로 조사하지 않고,
새로운 입력이나 새로운 형태의 불일치만 검토하는 것이다.

## 정본과 기본 분석 모집단

- 원본 API 경주: 24,436경주
- 원본 API 배당: 29,192,211행
- HTML 보완 후 canonical 배당: 29,196,005행
- 2020–2021 제외: 3,659경주
- 비코로나 무결과 제외: 95경주
- 기본 분석 대상: 20,682경주

무결과는 결과 자료의 유효한 양수 순위가 한 건도 없는 경주로 정의한다. 전체
145경주이며 2020–2021 50경주와 그 밖의 기간 95경주다. 원자료에서는 삭제하지 않고
`is_no_result`로 표시하되 기본 배당 분석에서는 제외한다.

## `9999.9`와 초과 배당

`9999.9`는 정상 경주의 유효한 마번 조합에서 일반적으로 표시상한이다. 참배당이
정확히 9,999.9라는 뜻으로 사용하지 않고 우측 검열값으로 취급한다.

다만 2018-07-01에는 표시상한이 해제된 배당판이 존재한다. 원본 API
`odds.jsonl.gz` 29,192,211행과 canonical Parquet 29,196,005행을 각각 전수 검사한
결과 `odds > 9999.9`는 이 날짜 하루에서만 발견됐다.

| 지역·승식 | 조합 행 | 경주 | 최소 초과값 | 최대값 |
| --- | ---: | ---: | ---: | ---: |
| 서울 삼쌍승(TRI) | 1,285 | 10 | 10,000.3 | 53,382.3 |
| 부경 삼복승(TLA) | 41 | 3 | 10,315.5 | 21,834.2 |
| 부경 삼쌍승(TRI) | 2,229 | 5 | 10,003.0 | 235,070.0 |
| **합계** | **3,555** | **15개 고유 경주·18개 승식판** | **10,000.3** | **235,070.0** |

따라서 값 처리 규칙은 다음처럼 고정한다.

- `odds == 9999.9`: 유효 조합이면 표시상한·우측 검열
- `odds > 9999.9`: 관측 점값으로 보존하며 `is_capped_odds=False`
- 현재 bundle에서 2018-07-01 이외 날짜에 초과값이 나오면 새 이상으로 경고

재현 쿼리의 핵심 조건은 다음과 같다.

```sql
SELECT rcDate, meet, pool_code,
       count(*) AS row_count,
       count(DISTINCT race_id) AS race_count,
       min(odds) AS min_odds,
       max(odds) AS max_odds
FROM read_json('odds.jsonl.gz', format='newline_delimited')
WHERE odds > 9999.9
GROUP BY ALL
ORDER BY rcDate, meet, pool_code;
```

## 개별 API 이상

### 2023-03-17 부경 8경주: 출전표 밖 자리표시자

API28_1 단승·연승에 등록 출전번호 밖 마번을 참조한 `9999.9` 72행이 있다. 단승
36행과 연승 36행이며 8경주에 걸쳐 있다. 정상 상한 배당이 아니라 무효한 자리표시자다.

- 처리: 조합 마번의 출전표 참조 무결성 검사에서 해당 72행만 제외
- 영향: 나머지 정상 `9999.9`는 보존
- 상태: KRA 신고 완료

### 2019-05-18 제주 6경주: `dusu` 불일치

API26_2의 `dusu`는 9지만 등록 출전표와 홈페이지 상세 결과는 모두 10두다.

- 처리: `dusu`를 분석용 출전두수로 직접 쓰지 않음
- `registered_count`: 출전표 행으로 재계산
- `starter_count`: 결과와 취소마 상태로 재계산
- 상태: KRA 신고 완료

전체 `dusu` 이상은 42경주로 빈 값 40건, 0 또는 무효값 1건, 실제 인원 불일치
1건이다.

## 취소·무결과 경주

`sales_missing_all=True`인 145경주는 유효 순위가 하나도 없는 145경주와 정확히
일치한다. odds 승식이 존재한다는 사실만으로 시행 경주라고 판정하면 안 된다. 일부
무결과 경주에는 전 승식 격자나 `9999.9` 자리표시자가 남아 있다.

대표적으로 2019-11-29 부경 1–11경주는 당일 문중원 기수 사망 후 모두 취소됐다.
11경주 모두 결과 순위와 HTML 상세 링크가 없고 API의 7개 승식 조합은 전부
`9999.9`다. 이 날짜는 이상 배당 후보가 아니라 취소·무결과 cluster다.

외부 근거: [연합뉴스, 2019-11-29](https://www.yna.co.kr/view/AKR20191129147300007)

## 2025-10-17 API 배당 공백

제주 8경주와 부경 8경주, 총 16경주에서 API28_1·API29_1의 WIN, PLC, QNL, EXA,
QPL 다섯 승식이 전부 비어 있다. 같은 경주의 sales와 TLA·TRI는 존재하고 KRA HTML
배당판에도 빠진 다섯 승식이 존재한다.

- HTML에서 보완한 유효 조합: 3,866행
- 제주: 1,562행
- 부경: 2,304행
- 처리: `source_type=html_backfill`, `source_name=KRA_HTML`로 출처를 남겨 보완
- 의미: 경주 취소나 미판매가 아니라 API endpoint 공백

## HTML과 API 경주 모집단

기존 HTML 아카이브는 지역별 전형 경주 요일을 기준으로 수집한 부분집합이다. 따라서
HTML에 없고 API에 있는 경주를 곧바로 API 오류로 보지 않는다.

- HTML 경주: 19,301
- 같은 기간 비교 가능 API 경주: 19,567
- HTML에 없는 API 경주: 266
- 지역별 전형 요일 밖: 184
- 전형 요일이지만 기존 수집 기준선과 겹치지 않은 경주: 82
- HTML에만 있는 경주: 0

공통 19,301경주의 출전번호·등록두수·취소마 집합은 모두 일치했다. 공통 유효 배당
24,263,109키의 값도 전부 일치했고 숫자 불일치는 0건이다.

## 재조사 기준

다음 중 하나가 생길 때만 새로운 데이터 이상 조사로 올린다.

1. 입력 bundle의 해시나 행 수가 바뀐다.
2. 2018-07-01 이외 날짜에서 `odds > 9999.9`가 나온다.
3. 유효 순위가 있는 경주에서 전 승식 또는 필수 승식 전체가 비어 있다.
4. 출전표 안의 유효 조합인데 API와 HTML의 숫자값이 다르다.
5. 조합 마번이 출전표 밖인데 알려진 2023-03-17의 72행에 속하지 않는다.
6. 위 문서화된 유형으로 설명되지 않는 경주·날짜 cluster가 나온다.

통계적으로 극단적인 배당은 데이터 오류와 다르다. 원천 간 불일치가 없으면 분석
검토 후보로만 유지하고 KRA 오류 신고 후보로 분류하지 않는다.
