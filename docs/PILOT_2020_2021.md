# 파일럿: 2020·2021년 수집

*작성 2026-08-18*

배경과 API 사양은 [API_FINDINGS.md](API_FINDINGS.md)를 따른다.
이 문서는 첫 수집 범위와 검증 방침만 정한다.

---

## 1. 범위

**2020년 1월 ~ 2021년 12월, 서울·제주·부경 3개 경마장.**

이 두 해는 기존 아카이브(2016-06~2025-12, 19,301경주)에 **통째로 빠져 있는
구간**이다. API는 두 해를 정상 반환하므로 복구할 수 있다.

수집 대상 API 네 종:

| 대상 | 엔드포인트 |
| --- | --- |
| 단승·연승 | `API28_1/singlePredictionRateInfo_1` |
| 복승·쌍승·복연승 | `API29_1/doublePredictionRateInfo_1` |
| 삼복승·삼쌍승 | `API30_1/triplePredictionRateInfo_1` |
| 승식별 매출액·당첨배당 | `API179_1/salesAndDividendRate_1` |

보조로 `API26_2/entrySheet_2`(출전표, 등록두수)와
`API214_1/RaceDetailResult_1`(착순)을 함께 받는다. 개최일 판별과 검증에 쓴다.

### 규모

2년 × 3경마장 × 12개월 × 4~6개 API. 경마장 × 월 단위 조회에
`numOfRows=100000`을 쓰면 **500회 미만**이면 끝난다. 일일 한도의 5% 미만이다.

## 2. 검증 방침

**API 데이터 자체는 신뢰한다.** 근거는 API 값과 KRA 배당판 HTML 값을 셀
단위로 804개 대조해 100.0000% 일치한 결과다(API_FINDINGS 2절).

따라서 검증의 대상은 API가 아니라 **수집·저장·변환 코드**다. 원본이 정확해도
페이지네이션을 빠뜨리거나 파라미터를 잘못 넘기면 데이터는 조용히 새어 나간다.
기존 아카이브의 누락 390경주도 원천이 틀려서가 아니라 수집기가 흘린 것이었다.

### 2.1 `totalCount` 대조 — 수집 완료 조건

```
API 응답의 totalCount  ==  실제로 저장한 행 수
```

이 등식을 **경마장 × 월 × API 단위로 기록하고 대조**한다. 어긋나면 그 조합은
미완료로 두고 재수집한다.

이 한 가지가 페이지네이션 누락, 조기 종료, 중복 저장을 전부 잡는다.
2020·2021은 대조할 기존 데이터가 없으므로 이것이 유일한 외부 기준이다.

### 2.2 내부 정합성 검사

| 검사 | 기준 |
| --- | --- |
| 행 수 = 조합 수 | 단승 `n`, 연승 `n`, 복승 `C(n,2)`, 쌍승 `n(n-1)`, 복연승 `C(n,2)`, 삼복승 `C(n,3)`, 삼쌍승 `n(n-1)(n-2)` |
| `n`의 독립 산출 | `API26_2`의 `dusu`와 취소마 정보로 구함. 배당 격자 자체에서 역산하지 않는다 |
| 오버라운드 | 승식별 `Σ(1/O)`가 환급률과 정합 (단승·연승 0.80, 나머지 0.73) |
| 매출액 역산 | `n = t·S / (100·O)`가 정수로 떨어짐 |
| 복승 이중 출처 | `API5`와 `API29_1`을 모두 받아 셀 단위 대조 |
| 승식 완전성 | 실제 개최일이라면 7승식이 모두 존재 |

### 2.3 개최일 판별

**요일로 판별하지 않는다.** 상세한 근거와 방법은 API_FINDINGS 5절을 따른다.
요약하면 **매출액과 착순이 있으면 실제 경주**이고, 둘 다 0이면 시험 기록이다.

걸러낸 날짜는 삭제하지 않고 별도 테이블에 보존한다.

## 3. 2020년 특유의 주의사항

### 3.1 빈 달·빈 날이 정상이다

코로나로 경마가 장기 중단된 기간이 있다. 표본 조사에서도 확인된다.

| 날짜 (서울) | 복승 셀 |
| --- | ---: |
| 2020-01-04 | 836 |
| 2020-02-15 | 739 |
| 2020-06-20 | 979 |
| 2020-07-18 | 884 |
| 2020-09-19 | **0** |
| 2020-10-17 | **0** |
| 2020-12-12 | 1,291 |

**`totalCount = 0`을 수집 실패로 처리하면 안 된다.** 중단 기간과 재개 시점은
데이터에서 확인해 기록으로 남긴다.

### 3.2 무관중 기간 플래그

2020·2021은 두 해 모두 무관중 또는 제한 시행 기간을 포함한다. 배당 격자는
정상이지만 **매출액이 평시와 크게 다르다.**

수집한 레코드에 **기간 구분 플래그를 붙인다.** 이후 시계열·유동성 분석에서
이 두 해를 평상시와 섞으면 결과가 왜곡된다. 기존 논문이 2020·2021을 표본에서
제외한 이유이기도 하다.

매니페스트의 `totalCount` 기록은 재수집·증분 수집 때 그대로 대조 기준이 된다.

## 5. 이후 확장

파일럿이 통과하면 같은 구조로 범위를 넓힌다. API가 제공하는 전체 범위는
API_FINDINGS 4절에 있다.

- 삼복승·삼쌍승 2009~
- 복승·쌍승·복연승 2007~
- 단승·연승 2002~
- 매출액 1991~

전 역사를 받아도 약 3,700회 호출이면 끝난다.

기존 아카이브 구간(2016-06~2025-12)까지 다시 받으면, 아카이브에 누락된
55개월·약 390경주가 함께 복구된다.
